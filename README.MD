# ClientFlow 🚀

Una **SaaS moderna e completa** per la gestione clienti con autenticazione sicura, dashboard interattiva e design professionale.

**[📁 Repository](https://github.com/rob587/Progetto-Saas)**

---

## 🎯 Che cos'è ClientFlow?

ClientFlow è un'applicazione full-stack production-ready che dimostra competenze avanzate in:

- **Autenticazione JWT sicura** con password hashing
- **API REST completa** con operazioni CRUD
- **Database MySQL** con design relazionale
- **Frontend moderno** con React + Vite

---

## ✨ Features

✅ **Autenticazione & Registrazione**

- Registrazione utenti con validazione email
- Login con JWT tokens
- Password hashing con bcrypt
- Sessioni persistenti con localStorage

✅ **Gestione Clienti**

- Visualizza, aggiungi, modifica e elimina clienti
- Dashboard con statistiche in tempo reale
- Tabella interattiva e responsive
- Modal form per operazioni CRUD

✅ **Sicurezza**

- CORS configurato
- Middleware di autenticazione
- Variabili d'ambiente protette
- Password validate e hashate

---

## 🛠️ Tech Stack

### Backend

- Node.js + Express
- MySQL Database
- JWT Authentication
- bcryptjs Password Hashing

### Frontend

- React 19 + Vite
- Axios HTTP Client
- React Router
- Bootstrap 5 + React Icons

---

## 🚀 Setup Locale

**Backend:**

```bash
cd server
npm install
# Crea .env con DB_HOST, DB_USER, DB_PASSWORD, DB_NAME, JWT_SECRET
npm run dev
```

**Frontend:**

```bash
cd client/frontend
npm install
npm run dev
```
